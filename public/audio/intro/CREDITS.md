# Голоса вступительной записи

Девять коротких реплик (`d1`–`d6`, `a1`–`a3`) созданы синтезом речи специально для этой игры по авторскому русскому тексту. Это не записи и не клоны голосов реальных людей. Персонажи «Артём» и «Лена» вымышлены.

Файлы распространяются вместе с игрой на тех же условиях, что и её исходный код и ассеты. Внешние звуковые библиотеки не используются. Уличный фон (ветер, птицы, машины) и шум плёнки синтезируются в реальном времени через Web Audio.
