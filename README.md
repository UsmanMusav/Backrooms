# BACKROOMS — Потерянный сигнал / MIMIC

Хоррор от первого лица с русским интерфейсом и визуальной стилизацией под эпоху PlayStation 3. **Версия 1.3.0: нейросетевые намерения Мимика, подмена ника участника, заметный чат с историей и редактирование ников. Для свободного диалога — необязательная серверная LLM; без неё работают маленькие локальные сети с ограниченными репликами.** Сохранены кооператив на 1–4 человека, портативный Windows EXE, браузерная версия и одиночная игра.

Жёлтые офисные лабиринты, процедурные обои и ковролин, мерцающие лампы, направленный фонарь, динамические тени, bloom, цветокоррекция и аналоговое зерно. Главное меню — живая трёхмерная сцена. Персонажи — локальные skinned GLB-модели на основе CC0-ассетов Quaternius; материалы окружения и звуки создаются программно. Модели, текстуры и шрифты входят в сборку: внешние игровые API и CDN для базовой игры не нужны. Внешняя LLM подключается только по выбору оператора сервера.

> Содержит мерцание, тревожные звуки и преследование. Это стилизация под PS3, **не игра для самой консоли**.

### Игра с друзьями в одной сети

1. Ведущий запускает EXE → **«Кооператив» → «Создать комнату»**. Поле сервера оставляет пустым, указывает ник. Ники людей в комнате должны различаться; менять их можно в лобби.
2. В лобби копирует **адрес сервера и шестисимвольный код**. Используется порт 8787, а если он занят — свободный порт; точный адрес указан в лобби. При нескольких сетевых адаптерах выбирайте адрес общей с друзьями сети.
3. Друзья запускают свои EXE → **«Присоединиться»**, вводят **адрес ведущего**, код и имя. Пустое поле на другом компьютере подключит его к собственному серверу, а не к ведущему. Вместо EXE можно открыть HTTP-адрес ведущего в современном браузере.
4. В стандартном запросе Windows Firewall разрешите игре доступ только в доверенной **частной сети**, если хотите принимать подключения. Игра сама не изменяет правила брандмауэра.
5. Все гости нажимают **«Я готов»**, ведущий — **«Начать экспедицию»**.

Один код работает только на одном сервере. Оставляйте приложение/компьютер, на котором запущен сервер, включённым: передача роли ведущего комнаты **не переносит сам сервер**.

### Через интернет

Автоматического проброса NAT, Steam/Epic matchmaking и предоставленного публичного хостинга нет. Нужен **общий доступный сервер**: собственный сервер с HTTPS/WSS, настроенный сетевой доступ или доверенная виртуальная LAN. Одного кода комнаты недостаточно.

Для самостоятельного хостинга:

```sh
npm ci
npm run build
npm start                       # HTTP + WebSocket, 0.0.0.0:8787
# PORT=9000 npm start            # другой порт в POSIX-оболочке
```

На публичном хосте рекомендуется HTTPS reverse proxy, который передаёт `/ws` как WebSocket, а остальные запросы — в тот же сервер. Все игроки открывают этот URL либо указывают его в EXE. В браузере с HTTPS разрешён только защищённый WSS; из EXE/HTTP можно подключаться и к WS. Подпапки URL не поддерживаются: WebSocket всегда находится по `/ws`. `GET /api/health` проверяет доступность сервера.

Комнаты приватны только за счёт непредсказуемого кода: аккаунтов и паролей нет. Не используйте чат для секретных данных. Сервер не сохраняет переписку или прогресс на диск; последние 40 строк живут в памяти комнаты. При подключённой внешней LLM часть публичной переписки и ники передаются провайдеру — это показано в лобби. Сообщения существуют в памяти сеанса и на подключённых клиентах.

## Что нового в 1.3.0

- Обученные локальные нейросети намерений и тем чата; необязательная серверная LLM для свободного диалога, с таймаутами/лимитами/отменой и честным fallback.

### Сохранённые улучшения 1.2.0

- **Настоящая skinned-модель:** непрерывная сетка тела, 65 костей и восемь подготовленных анимационных клипов. Костюм, защитные очки и рюкзак; отдельные скелеты и AnimationMixer у каждого человека и Mimic. Примитивные конечности заменены. Замаскированный Mimic использует в точности тот же ресурс и контроллер, что и человек.
- **Камера:** плавное покачивание по шагам, усиление при беге, мягкий наклон при движении вбок, инерция рук при осмотре и спокойное дыхание. Настройка «Покачивание камеры» отключает эти эффекты вместе с изменением FOV; настройка reduced-motion также учитывается.
- **Фонарь:** плавно поднимается и убирается за нижний край экрана; выключенный предмет с рукой действительно перестаёт рисоваться. Повторное быстрое нажатие F разворачивает движение без скачка. Рука взята из того же skinned-персонажа.
- **Графика:** normal/roughness-карты обоев, ковролина и потолка, контактное затемнение, влажные участки, кабели, розетки и следы предыдущих экспедиций. Свет меньше просачивается через стены. На низком качестве отключаются тени и уменьшается число активных светильников.
- **Предметы:** точёный металлический фонарь, керамические предохранители в держателях, щиток с тремя индикаторами и рычагом, более аккуратные ящики и полевые записи.
- **Звук:** варианты шагов по сухому/влажному ковролину, шорох ткани и бумаги, дыхание после бега, щелчки реле, замок двери, капли, трубы, радиопомехи, пространственное эхо шагов и звук раскрытия. Всё работает офлайн; уровень ограничивается компрессором.
- **Напряжение:** короткие провалы света, в том числе после второго предохранителя. Три необязательные записи рассказывают о поведении существа и дают ориентир на 20 секунд. Записи подбираются локально каждым игроком, основные цели по-прежнему общие и серверные.
- **Главное меню:** одиночная игра, кооператив, настройки, помощь и переключение звука — без декоративных карточек и псевдотелеметрии.

## Нейро-Мимик, ники и чат

Mimic использует **ту же цельную модель, анимации, имя и цвет костюма, что и настоящий участник**. В сетевой комнате даже на одного человека он может взять ник этого человека; в офлайн-solo представляется Сашей. Дополнительная смена маски выполняется вне близкой прямой видимости. У Мимика отдельный actor ID — чужие права/управление он не получает. До раскрытия нет вражеской метки; в лобби перечислены только люди.

**По умолчанию работают настоящие небольшие обученные нейросети, без интернета:** MLP выбирает, следовать, вести к цели, ждать, исследовать или заманивать, а вторая распознаёт тему короткой фразы. Мимик подстраивает скорость, плавно поворачивается, делает паузы и пользуется фонарём. Но это **не полноценная языковая модель**: локальные ответы составлены из авторских контекстных реплик. Сети обучены на синтетических примерах, не на переписке игроков; они не дообучаются во время игры и не гарантируют поведения, неотличимого от человека.

**Для свободной генерации реплик и решений** оператор общего сервера может подключить OpenAI-совместимую LLM: локальную, например отдельно установленную Ollama, либо удалённую через HTTPS. Ключ только в окружении сервера, никогда в браузере. Сервис/большие языковые веса/платный доступ не входят в игру. При ошибке или таймауте без остановки мира включаются локальные сети; интерфейс честно показывает статус. Конкретная реальная LLM пока не была проверена — интеграция покрыта HTTP-моками и WebSocket/браузерными тестами.

**[Инструкция подключения LLM, приватность и ограничения](docs/MIMIC-AI.md)** · [архитектура/данные встроенных сетей](shared/ai/MODEL-CARD.md).

- Ник задаётся при входе и редактируется в лобби; ники людей в одной комнате уникальны, зарезервированные имена запрещены, длина до 18 символов. Смена ника гостя снимает готовность. Подтверждённое имя запоминается локально, аккаунтов нет.
- Общий чат лобби и экспедиции: **Enter / T** или кнопка **«ЧАТ»**, Enter отправить, Esc закрыть. Время, история до 40 строк, ваш ник, индикатор нового сообщения, ограничение 160 символов и защита от спама. При наборе персонаж не двигается и не включает предметы. Q — короткий сигнал.
- Мимик видит общедоступную переписку и отвечает в том же чате от скопированного имени. Перед внешней обработкой в лобби показано предупреждение; не пишите секреты и личные данные. Нет микрофона, голосового чата и клонирования голоса.

«Доверие» приближённо вычисляется по сближению, вниманию и совместному движению, **не по реальным мыслям**. После минимального времени маскировки и накопления этих признаков существо раскрывается. Коллизии, урон, общие цели и поиск пути остаются под контролем сервера независимо от вывода сети.

После раскрытия **разорвите видимость, выключите фонарь и не двигайтесь**: Мимик проверит последнее замеченное место. Бег и близкие шаги снова выдадут вас. На близкой дистанции или прямо перед существом одного выключения фонаря недостаточно. Эта логика сохраняется и в solo, и в кооперативе.

## Как пройти

Найдите **3 общих предохранителя**, вернитесь к **щитку у входа**, восстановите питание и откройте **дверь рядом со щитком**. Если живой игрок открывает выход, выигрывает вся команда. Погибший остаётся на связи через рацию, но не может двигаться или взаимодействовать. Если погибли все, запись оборвана; ведущий может вернуть команду в лобби и начать заново.

| Управление | Действие |
| --- | --- |
| **W A S D** / стрелки | Перемещение |
| **Мышь** | Осмотр |
| **Shift** | Бег; запас выносливости восстанавливается |
| **E** | Подобрать предмет / взаимодействовать |
| **F** | Поднять / выключить и убрать фонарь |
| **H** | Ориентир к текущей цели на 12 секунд |
| **Enter** / **T** | Открыть общий чат в кооперативе |
| **Q** | Короткое сообщение «Держимся вместе.» |
| **Enter** / **Esc** в рации | Передать / закрыть |
| **Esc** / **P** | Локальная пауза |
| **F11** | Полный экран в EXE |

**В кооперативе пауза не останавливает мир и Mimic.** Выход игрока передаёт роль ведущего оставшемуся участнику, но закрытие приложения-сервера отключает всех. Позднее подключение во время раунда, автоматическое переподключение и сохранение прохождения пока не поддерживаются.

В браузерах без разрешения на захват курсора можно осматриваться, удерживая левую кнопку мыши. На телефоне доступны джойстик, зона осмотра, кнопки действий и текстовая рация. Качество графики, зерно, покачивание, чувствительность и громкость настраиваются и сохраняются локально.

## Разработка и сборка

Рекомендуется **Node.js 24.22.3** и npm. Браузер/сервер поддерживают Node 22.18+, но native-оболочка WebView требует Node 24+. При кросс-сборке скрипт сам получает закреплённый Node 24.22.3 из npm. Windows x64 — единственная целевая desktop-платформа.

```sh
npm ci
npm run dev                     # клиент + WebSocket на 0.0.0.0:5173
npm test                        # unit и настоящие WebSocket-интеграционные тесты
npm run build                   # TypeScript, dist/ и .desktop/server.cjs
npm start                       # production-клиент + multiplayer
npm run build:windows           # один Windows x64 EXE + SHA-256 + инструкции
npm run verify:windows          # структура PE, SEA, ресурсы, версия и checksum
npm run test:desktop             # smoke-test встроенного SEA-сервера/клиента/WebSocket
```

`npm run preview` показывает только статический клиент; для сетевой игры используйте `npm start` или `npm run dev`. `npm run desktop` — запуск исходной оболочки на Windows с Node 24+ и установленными runtime-компонентами.

Сборщик использует **Node SEA + WebView2**, а не BAT-файл и не ссылку на сайт. Windows Node 24.22.3 и native-модуль WebView 0.6.0 берутся из npm; кэш и промежуточные бинарники находятся в `.cache/backrooms-windows` и не входят в Git. Клиент, сервер, модели/шрифты, значок, native-модуль и уведомления о лицензиях внедряются в EXE. Подпись исходного Node удаляется, поскольку после внедрения она недействительна; подпись издателя игре не добавляется.

`npm run test:desktop` на Linux запускает тот же SEA-пакет во временном host-исполняемом файле: это проверяет отсутствие потерянных JS-зависимостей/ресурсов и сеть, **но не эмулирует Windows GUI**. Workflow `.github/workflows/windows.yml` собирает EXE на Windows runner, запускает unit/сетевые тесты и smoke-test, а затем публикует новую версию в GitHub Releases. Smoke-test проверяет встроенный сервер, но не является проверкой графического окна WebView2.

### Браузерные тесты

```sh
npx playwright install chromium
npm run test:e2e
# BROWSER_PATH=/path/to/chromium npm run test:e2e
```

Проверяются обученные сети, схемы нейропланов, HTTP-моки LLM/таймауты/отмена и fallback, подмена ников, история и изоляция ввода чата, реальные GLB/скелет/анимации, скрытие и повторный подъём фонаря, покачивание и его отключение, записи, потеря цели Mimic, одиночный цикл целей, меню и настройки, мобильные кнопки, два независимых кооперативных клиента, готовность и общий чат, сетевое перемещение, пауза, окончание раунда, передача ведущего, второй раунд, ошибки подключения и выход. `tests/browser-harness.html` и `tests/character-harness.html` — отдельные dev-only стенды; в production-сборку они не входят. Основная игра не предоставляет debug/teleport API.

## Публикация каждой версии на GitHub

Владелец проекта выбрал GitHub Releases для всех версий. При push workflow `.github/workflows/windows.yml` собирает игру на Windows, проверяет EXE и публикует ещё не существующий `v<version>` с готовыми файлами. Временные CI-артефакты хранятся 14 дней, а файлы **Releases** не зависят от времени жизни среды Arena или этих CI-артефактов.

Перед выпуском следующей версии:

1. Измените номер в `package.json` вместе с lockfile, например `npm version patch --no-git-tag-version`.
2. Добавьте секцию с этим номером в `CHANGELOG.md`.
3. Закоммитьте и отправьте изменения в **текущую рабочую ветку**. Не нужно вручную менять подписи в игре: клиент, native-окно, имя EXE и PE-версия берутся из `package.json`.
4. Дождитесь успешных заданий **Test and build Windows x64** и **Publish new version without replacing older releases** в Actions.

Публикация сначала создаёт черновик, загружает и проверяет все файлы, затем открывает релиз. Успешно опубликованный номер не используется повторно, `--clobber` не применяется. Повторный push того же номера сохраняет прежний релиз; для исправленного EXE увеличивайте номер. Черновик не заменяет уже опубликованную версию. Сборки пока отмечаются **pre-release**, пока нет ручного подтверждения работы Windows GUI и подписи издателя.

После локальной сборки `npm run release:check` проверяет комплект и показывает план публикации **без загрузки**. Автоматическая публикация использует стандартный `GITHUB_TOKEN` Actions с разрешением `contents: write`; личные токены, пароли и секреты в исходниках не нужны. Если Actions отключены в настройках репозитория, их необходимо включить для автоматических выпусков.

## Технологии и ограничения

TypeScript · обученные MLP / необязательная LLM · Three.js · WebGL 2 · Web Audio · Vite · ws · Node SEA · WebView2 · Playwright. Фиксированная связная карта, BFS, проверяемые сервером коллизии, дистанция взаимодействия, общие цели и Mimic. Лимиты сервера: 4 человека на комнату, 64 комнаты, 256 соединений, кадры до 4 КиБ, ограничение частоты сообщений и heartbeat. Это прототип кооперативной игры, не инфраструктура с аккаунтами, полной античит-защитой или гарантией работы в любой сетевой конфигурации.


## Лицензии персонажа и арт-пайплайн

Модель Quaternius Universal Base Characters Standard и Universal Animation Library Standard распространяются по **CC0 1.0**. Источники, точные tree SHA и исходные уведомления сохранены в `public/models/CREDITS.md`, `CC0-1.0.txt` и `Quaternius-Standard-License.txt`; те же уведомления входят в EXE и файл лицензий релиза. Сторонний код из репозиториев-зеркал не используется.

Готовые GLB и текстуры уже находятся в репозитории — обычной сборке не нужны Blender, Python или сеть к арт-источникам. Необязательное воспроизведение подготовки (из корня репозитория):

```sh
node scripts/fetch-character-sources.mjs    # gh, закреплённые CC0-блобы в .cache/
node scripts/prepare-character.mjs        # retarget и экспорт GLB средствами Three.js
python3 -m pip install --target .cache/asset-python pillow==13.0.0 numpy==2.4.6
PYTHONPATH=.cache/asset-python python3 scripts/paint-explorer.py
```

Исходные загрузки и Python-зависимости не добавляются в Git. Итоговая модель и адаптированные текстуры поставляются локально с игрой.
