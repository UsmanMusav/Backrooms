ЗАПУСК
Windows 10/11 x64, поддержка WebGL 2. Нужны Microsoft Edge WebView2 Runtime и Microsoft Visual C++ 2015–2022 Redistributable x64. Скачивайте отсутствующие системные компоненты только с сайта Microsoft:
https://developer.microsoft.com/microsoft-edge/webview2/
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

Node.js устанавливать не нужно. Запустите EXE двойным щелчком. Одиночная игра работает без интернета после установки runtime-компонентов. Игра не требует прав администратора. Сборка не подписана цифровой подписью; Windows может предупредить о неизвестном издателе. Не отключайте антивирус или системную защиту.
Проверка SHA-256 в PowerShell:
Get-FileHash .\Backrooms-Mimic-{{VERSION}}-Windows-x64.exe -Algorithm SHA256
Сравните результат с соседним файлом .exe.sha256.

ДРУЗЬЯ В ОДНОЙ СЕТИ (1–4 ЧЕЛОВЕКА)
1. Ведущий: Кооператив → Создать комнату; поле сервера оставить пустым.
2. Скопировать адрес сервера и код из лобби, передать друзьям. По умолчанию используется порт 8787; точный порт показан в адресе.
3. Гости: Кооператив → Присоединиться; ввести АДРЕС ВЕДУЩЕГО и код. Пустое поле в EXE гостя означает его собственный сервер, а не сервер ведущего.
4. При запросе Windows Firewall разрешать входящие соединения только в доверенной частной сети. Игра сама не меняет правила брандмауэра.
5. Гости нажимают «Я готов», ведущий — «Начать экспедицию».
Можно играть и через браузер, открыв HTTP-адрес ведущего. Если несколько сетевых адаптеров, нужен адрес общей с друзьями сети.

ЧЕРЕЗ ИНТЕРНЕТ
Нужен один общий доступный сервер (обычно HTTPS/WSS) или настроенная доверенная виртуальная LAN. Публичный сервер в комплект не предоставлен. Код комнаты сам по себе не пробрасывает NAT. Все участники должны использовать один и тот же адрес сервера. Закрытие приложения, в котором работает сервер, отключит всех; передача роли ведущего комнаты не переносит сервер на другой компьютер.

MIMIC
Использует модель, имя и анимации напарника; следует за игроками, останавливается, подстраивает скорость и повторяет сообщения общей текстовой рации. Раскрывается после условного «доверия»: сближения, внимания и времени рядом. Настоящие мысли человека игра определить не может. Микрофон не используется; записи и клонирования голоса нет.

ОБНОВЛЕНИЕ 1.2
Цельные skinned-персонажи с анимациями, новый фонарь и предметы, улучшенные материалы/освещение, дополнительные звуки, плавные шаги и инерция камеры. Покачивание можно отключить в настройках.
Выключенный фонарь убирается за экран, включённый поднимается. В лабиринте встречаются три необязательные записи: E — прочитать и получить ориентир на 20 секунд; каждый игрок читает их независимо. После второго предохранителя свет может ненадолго пропасть.
От раскрывшегося Mimic можно скрыться: разорвите прямую видимость, выключите фонарь и замрите. Он проверит последнее замеченное место; бег и близкие шаги снова выдадут вас. На близком расстоянии или прямо перед существом одного выключения фонаря недостаточно.

ЦЕЛЬ И УПРАВЛЕНИЕ
Три общих предохранителя → щиток у входа → дверь рядом со щитком. Если один живой игрок открывает выход, спасена вся команда.
WASD / стрелки — движение; мышь — осмотр; Shift — бег.
E — взаимодействие; F — поднять / убрать фонарь; H — ориентир на 12 секунд.
T — текстовая рация; Enter — отправить; Esc в рации — закрыть.
Q — «Держимся вместе.»; Esc / P — пауза; F11 — полный экран.
ПАУЗА В КООПЕРАТИВЕ НЕ ОСТАНАВЛИВАЕТ СЕРВЕР И MIMIC.
После гибели доступна рация. При окончании раунда ведущий возвращает команду в лобби. Нет сохранений, входа посреди раунда или автоматического переподключения.

ДИАГНОСТИКА И ПРОВЕРКА
Профиль, извлечённый native-модуль и лицензии: %LOCALAPPDATA%\Noclip\Backrooms-Mimic
При ошибке запуска: startup-error.log в этой папке.
Проверены структура PE/SEA и встроенный серверный пакет на Linux; одиночная и сетевая логика проверяются автоматическими тестами. Непосредственный запуск окна EXE на Windows в этой среде недоступен и не проверен. Это неподписанная тестовая сборка.

Содержит мерцание и громкие звуки. Рекомендуются наушники. Стиль эпохи PS3, не программа для самой PlayStation 3.
